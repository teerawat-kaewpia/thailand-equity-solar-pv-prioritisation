## เกณฑ์รับแหล่งข้อมูล

- **รับ:** เว็บไซต์หรือเอกสารของหน่วยงานรัฐเจ้าของข้อมูล (erc.or.th, pea.co.th, mea.or.th, egat.co.th, eppo.go.th, dede.go.th, ราชกิจจานุเบกษา) หรือ open-data ทางการ (data.go.th)
- **รับเฉพาะใช้อ้างสถานะ/บริบท:** รายงาน IEA/IRENA/World Bank, peer-reviewed paper (ห้ามใช้เป็นแหล่งตัวเลขรายจังหวัด ถ้าไม่ได้ระบุแหล่งข้อมูลทางการไว้)
- **ไม่รับ:** ข่าว/บล็อกเป็นแหล่งตัวเลข (ใช้ได้แค่ชี้ไปหาแหล่งต้นทาง), ข้อมูลที่ไม่ระบุปีหรือหน่วยงาน
- **ข้อมูลรายจังหวัดใช้ได้เมื่อ:** ครอบคลุม ≥ 70 จาก 77 จังหวัด, ระบุปี/วันที่ตัดข้อมูล, ระบุหน่วย (MW หรือจำนวนราย), ดาวน์โหลดหรือคัดลอกได้ทั้งชุด
- ทุกแหล่งที่ใช้ บันทึก URL + วันที่เข้าถึง + หน่วยงานที่ระบุใน "ที่มา" ลงใน `Docs\D_FINDINGS.md`

## ผลที่เป็นไปได้ และสิ่งที่ทำต่อ (กำหนดล่วงหน้า)

- D1 หรือ D2 ผ่านเกณฑ์: ใช้เป็นตัวเปรียบเทียบหลักใน §4.7 และเป็น outcome หนึ่งของ S ส่วน OSM ลดเป็น descriptive check
- D1/D2 ไม่ผ่าน: คง OSM ไว้แต่ระบุว่าเป็น utility-scale + ascertainment bias และไม่ใช้เป็น outcome ของ S
- D4 พบข้อมูลรายพื้นที่: ใช้แทนระยะ MV ในข้อ P ถ้าไม่พบ ให้ใช้ MV-proximity classes ตามแผน
